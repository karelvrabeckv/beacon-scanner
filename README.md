# Beacon Scanner

A mobile application for scanning IoT beacons.

Created for [the Saint Martin's Institute of Higher Education](https://www.stmartins.edu/) in Hamrun, Malta.

Powered by *Dart*, *Flutter*, and *Firebase*.
